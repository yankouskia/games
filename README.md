# 🎮 ИГРЫ ДЛЯ ДЕТЕЙ

Детская обучающая платформа с играми для детей 3–5 лет. Все на русском языке.

## Игры

### 🔗 Соедини
Соедини слово с картинкой. 300+ слов, бесконечные уровни.

### ✏️ Напиши букву
Обведи букву по точкам. Все 33 буквы русского алфавита.

## Разработка

```bash
# Установка зависимостей
npm install

# Запуск dev-сервера
npm run dev

# Сборка для production
npm run build

# Предпросмотр сборки
npm run preview
```

## Деплой

Приложение деплоится на GitHub Pages из папки `docs/`.

```bash
# Собрать и задеплоить
npm run build
git add docs/
git commit -m "deploy"
git push
```

В настройках репозитория GitHub Pages должен быть настроен на папку `docs/` ветки `main`.
